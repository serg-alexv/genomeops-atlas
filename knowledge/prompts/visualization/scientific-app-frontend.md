# Scientific app frontend

Pipeline:

1. Ground the scientific question and evidence states with a reasoning model.
2. Define the typed data model and interaction contract with an architecture agent.
3. Use a fast coding model for focused visualization components and UI iteration.
4. Run accessibility, responsive, unit, and production-build checks.
5. Deploy a preview; promote only after human review.

Required UI states:
- confirmed
- predicted
- unknown
- needs validation

Never render model consensus as experimental confirmation.
